# SYARAT PENGGUNAAN SOURCE CODE

Silakan sesuaikan isi dokumen ini dengan perjanjian antara penjual dan client.

## Lisensi Non-Eksklusif

Jika source code dijual sebagai lisensi non-eksklusif:

```txt
Client boleh menggunakan source code untuk bisnisnya sendiri.
Penjual masih boleh memakai, mengembangkan, atau menjual template/source code sejenis ke pihak lain.
Client tidak boleh menjual ulang source code mentah tanpa izin tertulis.
```

## Lisensi Eksklusif

Jika source code dibeli secara eksklusif:

```txt
Client mendapatkan hak penggunaan penuh sesuai perjanjian.
Penjual tidak menjual ulang versi yang sama kepada pihak lain.
Harga eksklusif harus lebih tinggi dari source code biasa.
```

## Catatan

Dokumen ini bukan nasihat hukum. Untuk kontrak resmi, gunakan perjanjian tertulis yang disetujui kedua pihak.
